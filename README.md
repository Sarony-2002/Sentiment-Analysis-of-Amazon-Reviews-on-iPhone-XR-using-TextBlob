# Sentiment Analysis of Amazon Reviews on iPhone XR

This repository features our team’s project for **ARTI 402: Programming for Artificial Intelligence** course. 

## Overview
This project delivers a sentiment analysis pipeline to evaluate over 5,000 Amazon reviews of the iPhone XR in India. The workflow emphasizes data preprocessing, natural language processing using TextBlob, consistency checks, and data visualization to understand public customer satisfaction.

## Tech Stack
- **Language:** Python
- **NLP & Sentiment Analysis:** TextBlob
- **Data Processing & Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib
